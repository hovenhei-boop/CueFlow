## 已实现

当前唯一字幕链为：

```text
Frozen TimelineAudio + sealed Transcript
  → ATA submit/query
  → 完整 AtaResponse blob + invocation/checkpoint
  → 原序 utterances + diagnostics / AtaResult
  → current/sealed/stale 与 SRT serialization validity
  → SrtRender + output/subtitles.srt
```

### 句级直出与原始证据

- 请求使用 url + 原样 audio_text、caption_type=speech、sta_punc_mode=3。按官方协议读取
  id/query blocking=0；code=0 成功、2000 处理中，其他状态明确失败，不保留旧状态别名。
- Provider 不消费 words，不 atomize，不做字符关联、时间插值或本地分句。
  规范化只读取 utterances[].text/start_time/end_time，时间字段须为非 bool 整数毫秒。
- 成功 query 的 response.content 完整 bytes 以 blob 落盘，不 JSON 重编码、不使用 64 KiB
  diagnostic 截断策略。AtaResponse 保存 actual audio_text、metadata、Run 和冻结输入身份。
- raw Artifact、成功 invocation 与 checkpoint 同事务。字段缺失导致后续规范化失败，
  或 serializer 失败，都保留已成功提交的 raw、task ID 和调用记录。
- raw 提交事务本身失败时，成功状态/current/checkpoint 一起回滚，保留已知 task ID，
  仍要求显式重试，不从未引用文件推断调用已安全完成。

### 非阻断诊断与 serializer

- diagnostics 保存 utterance_count、text_comparison（relation、input_length、output_length、
  length_delta）、empty_text_count、negative_time_count、reversed_interval_count、
  zero_duration_count、overlap_count。它们永不影响导出状态。
- 比较的是实际 audio_text 与 ATA 原序文本拼接，不 strip、不 Unicode 归一化。
  长度按 codepoint；空文本仅指 ""; 负时间按句子计；重叠为相邻句子的严格非空时间交集。
- serializer 逐句编号、格式化毫秒并原样写 text。标点、空白、换行、词内符号不加工。
  空数组输出空文件；空 text、零时长、重叠、时间顺序倒退、超媒体时长、长句、文字变化可导出。
- 负端点或 start>end 只在 serializer 抛 SrtSerializationError，Run failed，不进入人工 review，
  不夹紧、不排序、不修正时间；生成完整文本后才原子替换目标文件，失败不覆盖旧文件。

### 状态与恢复

- Export 保留在盘 schema/hash、current/stale、当前 Run checkpoint、sealed resolution、
  实际请求文本、MediaObject/TimelineAudio 字节绑定、精确依赖边、成功 ATA invocation、
  response ID、raw blob 存在/hash 检查，不比较 ATA 输出是否等于 Transcript。
- 相同语义 Artifact 再次发布时，created_at 不参与身份比较，与现有内容寻址契约一致。
  跨 Run、内存篡改、raw 丢失/损坏、stale 或错误 invocation 仍拒绝导出。
- AtaResult 在序列化前提交本地 checkpoint。恢复只做未完成的本地步骤，不重发 ATA。
  确定性的字段错误/非法时间不会因 resume 被悄悄修正。
- ATA 已成功提交后，CLI 不再把更早的付费失败记录当作当前本地错误的 retry 建议。

### 删除与范围

物理移除 atomizer.py、alignment.py、segmentation.py、qa.py；移除 atoms、atomizer/mapper/
segmenter/QA 版本与配置、旧 Artifact kinds、下游失效引用、结果 ID 和专属测试。
替换为 ata_result.py、句级 Provider/serializer 测试；当前文档全部改写为句级契约。
没有保留 wrapper、旧数据转换、迁移、兼容分支或闲置旧主链。

保留独立的纠错 text_diff/候选投影和 review/needs_review；它们不是字幕时间映射。
既有声学裁决/VocaSync/旧提示词删除保持原状。没有新增运行依赖或升级开发环境依赖。
未删除真实项目、数据库、用户输入或已有调试证据。验证输出只放在独立的忽略目录。
本轮未提交、推送或重置 Git；工作区保留待审阅的实施 diff，“清理”不等于丢弃未提交工作。

## 偏差与剩余风险

没有偏离已批准的职责边界。修复的是中断残留、导出内容身份比较与本地失败恢复提示，
没有追加模型变更、质量评分、标点美化或新的付费实验。

未进行新版 ATA/ASR/纠错/GLM 真实云端全链验收，不能据离线替身断言真实字幕准确率。
此前真实调试未产出 SRT、GLM 严格 JSON 失败的历史结果，均不是新版通过的证据；
本轮没有覆盖或抹掉这些历史调用记录。

空数组、空 cue、零时长、重叠或句内空行在不同播放器上的表现可能不同；
当前按批准契约保留，而非保证播放器呈现效果。ATA 原始正文可能很大或含敏感信息，
只保存在项目 blob 中。存储继续受现有 RFC 8785/I-JSON 可表示数据范围约束；
这不是新加的时间质量阈值。没有本地重分句或质量恢复 fallback。
