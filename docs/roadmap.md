# CueFlow Roadmap

## v0.1.1 — Source 主链冻结

Source Media → Transcript → Alignment → Subtitle → QA → SRT。Source 身份、时间轴、Glossary 仅提示、对齐与 SRT 行为继续按 v0.1.1 契约运行。

## v0.2.1 — Reference Evidence 旁路

已实现 Reference 登记/relocate、确定性文档和字幕提取、冻结视频路由、可选 Reference ASR/Vision/Cloud Document Parse、provenance、独立 Run/outcome、work-item retry 和 bundle。没有 UI，也没有把 Evidence 接入 Source 主链。

## v0.2.2+ — 未实施

术语/词库、terminology mining、candidate、acceptance、证据融合、Reference Evidence 与 Source 工作流的产品化消费、Supplementary PPT/板书/屏幕画面抽取，以及 UI 都必须经过后续独立设计与批准。v0.2.1 不包含这些能力的实现或桩。
